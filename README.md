# unsparkle.com

The public landing page for **Unsparkle**, a third-person action roguelite by Hungry Bunny Games.

This repository contains the website only. The game itself lives in a separate private repository.

## How it works

- `index.html` — the entire site. Plain HTML and CSS, no build step, no dependencies.
- `CNAME` — tells GitHub Pages this repo answers to `unsparkle.com`. Do not delete.
- `.nojekyll` — tells GitHub Pages to serve the files as-is.

## To change the site

Edit `index.html`, commit, push. GitHub rebuilds within about a minute.
